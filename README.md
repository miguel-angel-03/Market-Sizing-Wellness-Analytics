# Market-Sizing-Wellness-Analytics
Data-driven market sizing &amp; financial feasibility study for a wellness subscription model in Colombia. Built with Python, BigQuery, and Power BI using CRISP-DM methodology.
his repository executes a comprehensive end-to-end analytical pipeline to quantify the market potential for a conceptual activewear and wellness subscription brand in Colombia (2025).

### Key Project Highlights
* **Methodology:** Followed the **CRISP-DM** framework from Business Understanding to Deployment.
* **Data Engineering:** Automated ETL pipeline processing 1M+ raw macroeconomic records (DANE GEIH) via **Python** and **Google BigQuery**.
* **Strategic Insights:** Identified a high-precision **SOM of 12,319 users**, projecting a **$3.36B COP Net ARR**.
* **Business Intelligence:** Interactive **Power BI Dashboard** for geographic and demographic drill-down (Bogotá & Antioquia focus).
